Budgt.in: Navigasi Finansial Cerdas Generasi Z

Budgt.in adalah sebuah sistem manajemen keuangan otomatis yang dirancang khusus untuk membantu anak muda dengan rentang usia 17-25 tahun dalam mencapai stabilitas finansial dan target masa depan. Proyek ini dikembangkan sebagai bagian dari Program Kreativitas Mahasiswa - Karsa Cipta (PKM-KC) 2024.
- Latar Belakang & Masalah
  Banyak generasi muda menghadapi tantangan finansial yang unik, seperti:
  Mahasiswa (Persona Nunez): Tidak mencatat pengeluaran dan sering terjebak perilaku "lapar mata".
  Freelancer (Persona Modric): Pendapatan tidak tetap dan kesulitan menentukan strategi untuk mencapai target besar seperti laptop atau modal bisnis.
  Sandwich Generation (Persona Chesta): Beban finansial keluarga yang berat dan kesulitan mengalokasikan gaji secara proporsional antara kebutuhan pribadi dan orang tua.
  
-Fitur Utama
Sistem ini menyediakan solusi fungsional melalui beberapa fitur kunci:
  Manage Finance (Tracking Otomatis):
  Menambahkan pemasukan (Add Income) dari berbagai sumber (gaji, freelance, uang saku).
  Menambahkan pengeluaran (Add Expense) yang secara otomatis memperbarui saldo dan budget bulanan.

Budget Allocation:
  Pembagian anggaran otomatis untuk kategori tertentu (misal: keluarga vs pribadi) agar pengeluaran tetap terkontrol.
  Saving Goal & System Recommendation:
  Pengguna dapat menetapkan target tabungan (seperti mobil atau rumah) beserta tenggat waktunya.
  System Recommendation: Sistem secara otomatis menghitung dan memberikan rekomendasi jumlah tabungan bulanan yang harus disisihkan untuk mencapai target tepat waktu.
  Financial Report & Goal Track:
  Laporan visual mengenai total pemasukan dan pengeluaran.
  Pelacakan progres tabungan melalui fitur Goal Track Tabungan.

-Teknologi
Framework: Flutter (Mobile App)
Logika Sistem: Automated Update Saldo & System Recommendation Algorithm.
Arsitektur: Clean Architecture (direkomendasikan untuk pengembangan berkelanjutan).

- Tahap Pelaksanaan
Proyek ini mengikuti metodologi pengembangan karsa cipta yang mencakup:
Analisis Kebutuhan User: Berdasarkan persona mahasiswa, freelancer, dan karyawan.
Perancangan Sistem: Menggunakan Use Case Description yang mendetail.
Konstruksi: Pengembangan kode program menggunakan teknik vibecoding.
Pengujian: Validasi fungsi laporan dan akurasi rekomendasi sistem
